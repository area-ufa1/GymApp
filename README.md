# 🏆 GymQuest

Мобильное веб-приложение (PWA) для отслеживания тренировок с геймификацией.
Построено на основе личного плана: сплит 4 дня/нед, расчёт 1ПМ по Эпли, уровни силы,
замеры тела и цель по соотношению Плечи/Талия.

## Возможности

- **Тренировки** — лог подходов «вес × повт», сравнение с прошлой неделей по 1ПМ
  (🟢 сильнее / 🟡 так же / 🔴 слабее), таймер отдыха.
- **Сила** — ввод лучшего подхода → авто-расчёт 1ПМ (Эпли), лестница уровней
  (Старт → Элита), «сколько кг до следующего тира».
- **Питание** — дневник КБЖУ: авто-расчёт нормы (Mifflin-St Jeor + активность +
  профицит/дефицит), приёмы пищи и своя база продуктов (на 100 г), кольца макросов,
  график калорий за неделю.
- **Прогресс** — графики: соотношение Плечи/Талия с целью 1.60 и прогнозом даты,
  сумма 1ПМ, тоннаж и частота по неделям; календарь-теплокарта, объём по группам мышц,
  дневник веса тела; ввод замеров тела; история тренировок.
- **Геймификация**
  - Осмысленный XP и уровни (за тренировки, побитые подходы, рекорды, замеры).
  - Титул по силе (синхронно с тирами Старт→Элита).
  - Серии (streak) по неделям с учётом сплита.
  - Карточка персонажа: Сила / Эстетика / Объём / Постоянство.
  - Недельные квесты, боссы-рубежи, тоннаж-вехи, фото-прогресс.
  - Достижения: 11 целевых (привязаны к числам из таблицы) + игровые.
- **Профиль** — редактор плана, экспорт/импорт JSON, сброс.
- **PWA** — работает офлайн, можно «установить» на телефон.

Все данные хранятся локально в браузере (`localStorage`). Бэкенда нет.
Для переноса на другое устройство используйте экспорт/импорт JSON.

## Запуск локально

Это статический сайт без сборки. Нужен любой статический сервер (из-за ES-модулей
открывать `index.html` напрямую через `file://` нельзя):

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Деплой на GitHub Pages

1. Запушьте репозиторий на GitHub.
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**
   (workflow `.github/workflows/pages.yml` опубликует сайт автоматически),
   либо выберите **Deploy from a branch** и ветку с корнем `/`.
3. Откройте выданный URL на телефоне и «Добавить на главный экран».

## Технологии

Чистый HTML + CSS + JavaScript (ES-модули), без фреймворков и внешних библиотек.
Графики — собственный лёгкий SVG-рендерер (`js/lib/chart.js`), поэтому приложение
полностью работает офлайн.
